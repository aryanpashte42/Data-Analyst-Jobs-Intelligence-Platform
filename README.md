# Data Analyst Jobs Intelligence Platform

## Overview

The Data Analyst Jobs Intelligence Platform is an end-to-end analytics project designed to analyze job market trends for Data Analyst roles. The project transforms raw job posting data into actionable insights related to salaries, skills demand, company hiring patterns, location trends, and work arrangements through an interactive Streamlit dashboard.

The objective is to help aspiring analysts, job seekers, and professionals understand current market requirements and make data-driven career decisions.


## Business Problem

The data analytics job market is highly competitive, making it difficult for candidates to identify:

* High-paying opportunities
* Most in-demand technical skills
* Companies actively hiring Data Analysts
* Location-wise job distribution
* Work arrangement trends

This project addresses these challenges by leveraging Python, SQL, Excel, and Streamlit to extract meaningful insights from real-world job listing data.
